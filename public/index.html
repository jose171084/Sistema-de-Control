Zona de Limpieza para Pruebas

¿Cómo activar la persistencia permanente con Supabase en Render?

Paso 1: Entra a tu cuenta gratuita en Supabase.com y en tu proyecto ve a Storage > New bucket. Nómbralo database.

Paso 2: Ve a Project Settings > API y copia la Project URL y la clave anon / public.

Paso 3: En tu panel de Render, abre tu servicio web, entra a Environment Variables y agrega:

  • SUPABASE_URL = Tu URL de Supabase
  • SUPABASE_KEY = Tu clave de Supabase

¡Listo! Al reiniciar Render, el sistema descargará y mantendrá la base de datos de tu Beta Tester siempre guardada en la nube sin borrarse jamás.
